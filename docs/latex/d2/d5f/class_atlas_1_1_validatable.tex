\doxysubsection{Detailed Description}
A framework class that provides functions to a child class that allows it to have validation functionality. 

\begin{DoxyNote}{Note}
Below is some examples on how to use this class\+:
\end{DoxyNote}
\begin{DoxyParagraph}{Introduction}
Lets say you are designing a class called {\ttfamily My\+Class} that is executes operations that require certain things to be valid and needs to have checks that determine if it is valid. This is the perfect use case of the class {\ttfamily \doxylink{class_atlas_1_1_validatable}{Validatable}} as the inheritor class needs to be {\bfseries{validatible}} (shocking, right?
