\doxysubsection{Detailed Description}
Wraps a {\ttfamily Vk\+Viewport} instance, providing functions to interact with it, along with some safety checks. Furthermore, it allows you to skip the boilerplate code for dynamically setting the viewport. 

\begin{DoxyNote}{Note}
Before setting the viewport, please note that The viewport\textquotesingle{}s position should be considered the {\bfseries{top left corner}} of the viewport. Additionally, the viewport\textquotesingle{}s minimum and maximum depth {\bfseries{can}} be set to anything you want since the {\bfseries{minimum}} depth can be less than, equal to, and/or greater than the {\bfseries{maximum}} depth. This was noted in the Vulkan specifications.
\end{DoxyNote}
