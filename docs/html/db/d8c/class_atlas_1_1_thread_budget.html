Detailed Description

A class that represents a thread budget. It can be used to limit the amount of threads that can be used in a multi-threaded environment. Alternatively, an edge case of this is that it can be used to limit the amount of tasks that can be executed in a multi-threaded environment or just provide a "budget" for something.

Note
This class cannot be inherited.
