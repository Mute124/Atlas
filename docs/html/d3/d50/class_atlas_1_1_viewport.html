Detailed Description

Wraps a VkViewport instance, providing functions to interact with it, along with some safety checks. Furthermore, it allows you to skip the boilerplate code for dynamically setting the viewport.

Note
Before setting the viewport, please note that The viewport's position should be considered the top left corner of the viewport. Additionally, the viewport's minimum and maximum depth can be set to anything you want since the minimum depth can be less than, equal to, and/or greater than the maximum depth. This was noted in the Vulkan specifications.
