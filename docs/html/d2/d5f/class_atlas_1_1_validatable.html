Detailed Description

A framework class that provides functions to a child class that allows it to have validation functionality.

Note
Below is some examples on how to use this class:
Introduction
Lets say you are designing a class called MyClass that is executes operations that require certain things to be valid and needs to have checks that determine if it is valid. This is the perfect use case of the class Validatable as the inheritor class needs to be validatible (shocking, right? The class is named for it after all). Below is the original class definition of MyClass without the Validatable class:
class MyClass {
private:
MyHook mMyHookHandle;
public:
// Constructors go here...
bool isValid() const { return mMyHookHandle != nullptr; }
};
